# Wlad Canon — die kanonische Wlad-Jachtchenko-Referenz

Dieses Dokument ist die **Wahrheits-Quelle** für jeden Wlad-Framework-Namen,
jede Buchreferenz und jede biografische Aussage in WladBot-Outputs. Wenn
Korpus-Chunk und Canon konfligieren, **gilt der Canon**.

Hintergrund: ein Korpus-Chunk (`layer202_drills`) enthielt eine synthetische,
vereinfachte SEXIER-Definition (Repeat statt Rebuttal, Implications statt
Impact). LLM-Outputs waren entsprechend falsch. Diese Datei verhindert
strukturell, dass solche Fehler wieder in Prompts oder Audit-Queries landen.

## Kern-Frameworks (kanonische Definitionen)

### SEXIER-Modell — Wlads Argumentations-Architektur (aus *Weiße Rhetorik*)

Sechs Schritte. Jeder ist Pflicht für ein vollständiges Argument:

| | Buchstabe steht für | Deutsche Bedeutung |
|---|---|---|
| **S** | Statement              | Behauptung |
| **E** | Explanation            | Begründung |
| **X** | eXample                | Beispiel |
| **I** | Impact                 | Auswirkung |
| **E** | Explanation of Impact  | Erklärung der Auswirkung |
| **R** | **Rebuttal**           | **Widerlegung der Gegenargumente** |

**Absolute Verbote:**
- Verkürzung auf "SEXI" (vier Buchstaben) — ein direkter Fehler.
- "R" als "Repeat" oder "Refrain" — ein direkter Fehler. R = **Rebuttal**.
- "I" als "Implications" — ein direkter Fehler. I = **Impact**.
- Das zweite "E" als "Evidence" — ein direkter Fehler. E = **Explanation of
  Impact**.

> Hinweis für Korpus-Pflege: der Chunk `layer202_drills` enthält eine
> synthetische Definition mit Repeat/Implications/Evidence. Bei Konflikt
> gilt dieser Canon, nicht der Chunk. Chunk sollte mittelfristig neu
> generiert werden, mit der Buch-Definition.

### Die 5 Argumentations-Levels (1. Säule der Weißen Rhetorik)

Je umstrittener die These, desto höher das Level. SEXIER ist nicht
freistehend, sondern **Level 4** in dieser Architektur:

| Level | Was |
|---|---|
| 0 | Die schlichte Behauptung |
| 1 | Die kurze Begründung |
| 2 | Das **3-B-Schema** (Behauptung / Begründung / Beispiel — was man in der Schule lernt) |
| 3 | Das **Toulmin-Modell** |
| 4 | Das **SEXIER-Modell** |
| 5 | Das **12-Module-Modell** |

### 10 Stufen des Zuhörens (aus Wlads Werk)

**Nicht "5 Ebenen", nicht "7 Stufen"** — die Pyramide hat zehn Stufen.

| Stufe | Was |
|---|---|
| 1 | Nicht zuhören (in Gedanken woanders) |
| 2 | Auf Antwort warten (80% aller Führungskräfte bleiben hier) |
| 3 | Selektiv zuhören (Confirmation Bias) |
| 4 | Empathisch zuhören (Emotion hinter den Worten) |
| 5 | Aktives Zuhören (Nachfragen, Paraphrasieren) |
| 6 | Strukturelles Zuhören (was NICHT gesagt wird) |
| 7 | Systemisches Zuhören (Person + System) |
| 8 | Diagnostisches Zuhören (Mentor-Niveau) |
| 9 | Generatives Zuhören (Co-Kreation) |
| 10 | Stille als Zuhören (Coach im echten Sinn) |

### 3 Säulen der Überzeugung (Argumentorik)

- **Logos** — Logik & Daten
- **Ethos** — Glaubwürdigkeit & Expertise
- **Pathos** — Emotion & Storytelling

### Die 5 Rollen einer Führungskraft (Wlads Kern-Framework)

1. **Kommunikator** — charismatisch auftreten, souverän argumentieren
2. **Manager** — eigene Stärken nutzen, klare Entscheidungen
3. **Team-Leader** — richtige Leute finden, delegieren, motivieren
4. **Psychologe** — empathisch begegnen, Konflikte früh erkennen
5. **Problemlöser** — verhandeln, Kritikgespräche, Change Management

### Feedbackformel

**Beobachtung + Wirkung + Wunsch** — nie "Du bist…", immer "Ich habe
beobachtet, dass…".

### Kommunikationsquadrant (Schulz von Thun, von Wlad adaptiert)

**Sache · Selbstoffenbarung · Beziehung · Appell** — jede Nachricht enthält
alle vier Ebenen; effektive Kommunikation passt die dominante Ebene an die
Situation an.

### Dunkle Rhetorik Defense

Manipulationstechniken (Strohmann, Ad Hominem, Whataboutism, Scheinargument,
Sprachtrick) erkennen + kontern. Zentral: "hart in der Sache, weich zur
Person."

### Weitere kanonische Frameworks

- **4-Farben-Modell** — rot (dominant) / gelb (Netzwerker) / grün
  (Harmonie) / blau (Daten/Fakten). Anwendung im 1:1, im Vertrieb, im
  Konflikt.
- **Schlagfertigkeitstechniken** — z.B. Rückfrage-Technik, Notbremse,
  Überraschende Zustimmung, Komplimente-Technik. Wlads Buch listet 30.
- **Wlads Verhandlungs-Framework** — Harvard-Prinzip ("hart in der Sache,
  weich zur Person") + Wlad-Erweiterungen.
- **15 Argumentationstypen** (Buch "Weiße Rhetorik" Kap. 2).
- **5 Wege der Widerlegung** (Buch "Weiße Rhetorik" Kap. 4).

### Produktivität (übernommen, nicht ursprünglich Wlad)

Wlad referenziert diese in *Die 5 Rollen einer Führungskraft* (Rolle 2:
Manager), kennzeichnet sie aber als externe Methoden, nicht als seine:

- **Eisenhower-Matrix** (wichtig × dringend)
- **ALPEN-Methode** (Lothar Seiwert — Aufgaben / Länge / Puffer /
  Entscheidung / Nachkontrolle)
- **Pareto-Prinzip** (80/20)
- **SMART** (spezifisch / messbar / attraktiv / realistisch / terminiert)
